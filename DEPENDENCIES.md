# Dependencies

## Required

- A modern web browser with support for standard HTML and CSS, including Flexbox, Grid and media queries.
- `Profile3.png` in the same directory as `index.html` for the portrait.

The page uses system fonts: Arial, Helvetica or the browser's default sans-serif font. No font download is required.

There are no npm packages, pip packages, JavaScript libraries or build tools to install.

## Optional

Python 3 can serve the site locally using its standard-library HTTP server:

```sh
python -m http.server 8000
```

Python is unnecessary when opening `index.html` directly or viewing the site on a static web host.

## Contact links

The email and SMS links rely on the visitor's device having a suitable application configured. Miro is mentioned as a tool used during lessons; it is not a website dependency.
